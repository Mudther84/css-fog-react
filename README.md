# CSS Fog — React + Redux Toolkit (Create React App)

Three games that teach CSS: properties (64 levels), selectors (14), speed quiz (12). Arabic / French / English, dark & light mode.
Every page and game has its own colour and its own 3D shape (Home keeps the original green cube):
Home green · Login orange (pyramid) · Signup blue (carousel) · CSS properties purple (box-model layers) · Selectors pink (target) · Quiz yellow (rings).

```
npm install
npm start        # development
npm run build    # production build (relative paths, HashRouter)
```

State: Redux Toolkit slices `auth`, `settings`, `progress` (saved in localStorage). No gradients anywhere.
